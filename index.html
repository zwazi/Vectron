Help & Reference

Tools

ToolKeyDescription
Select1 / SClick an object to select it. Drag on empty space to box-select. Click a selected object to deselect. Del deletes the selection.
Wall2 / WOpen the Wall Tool window to choose freeform walls, rectangles, circles, arcs, ellipses, or text walls. For shape tools, click the requested points, set the wall count if prompted, then press Generate Walls. Text walls use a typed string, a two-corner box, and Submit. Double-click or press Shift+W to finish freeform walls. Press Esc to cancel.
Upper Floor3 / FOutline a walkable upper floor with at least three clicks. Level 0 is implicit. Double-click or press Shift+F to finish; Esc cancels.
Zone4 / ZChoose a type and shape, then follow the placement hint. Line zones use two endpoint clicks and the configured width. Shift+Z cycles zone types.
Spawn5 / S SClick to place a spawn point. Move the cursor to set the spawn direction, then click again to confirm.
Ramp6 / RClick two points for the edge on the current level, switch levels with the menu below, then click the two points for the other edge.
Wall Split7 / S S SClick on a wall to split it at the nearest point. Hover over the wall to see the split preview.
Wall Join8 / JClick the endpoint of one wall, then the endpoint of another to merge them into a single wall.
Vertex Move9 / VClick to select a wall, then drag its vertex dots to reposition them. Del deletes the selected vertex.

Map and Level Controls

NameMap name included in the exported file
AuthorAuthor name included in the exported file
TagsComma-separated search tags (for example racing, technical).
RevisionGenerated internally from the complete persisted map on export; it is not an editable map field.
Axes ☐Number of axes (turning directions). axes = 360 / angle. Check the box to include this in the exported map file.
LevelsOpen the Levels menu in the bottom bar to select or hide any level, or create a new one.
Gap heightsSet the vertical height between every adjacent pair of levels in the Levels menu.

Vectron 1.2 — Arma Racing Edition

A map editor for Arma Racing maps. It was originally written in 2008 by Carlo Veneziano, then re-written 2010 as a Flash-based map editor, then re-written in 2014 by Tristan in Javascript. (David Dubois is also credited.)

The project was pretty much inactive until around 2017, when someone requested it be added to my (Armanelgtron) site. However, it still essentially remained with very few changes until 2021 when I finally decided to attempt to fix some annoyances and improve upon it.


Source code available at github.com/zwazi/ArmaRacing.
