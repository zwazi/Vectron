# Vendored Armawebtron

This directory vendors the browser build from
`https://github.com/Armawebtron/Armawebtron` at commit
`f5dc24375af0854c9e9bc59bae3fddd90aba8bc3`.

Armawebtron is licensed under GPL-2.0-or-later. The upstream `COPYING` file is
included here. `vectron-preview-receiver.js` is the Vectron integration layer
that loads an editor map directly, without a userscript or third-party host.
